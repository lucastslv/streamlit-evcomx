# Apoio à apresentação final

Esta pasta reúne o material de apoio do app para a apresentação de 15 minutos + 10 de perguntas.

- `roteiro_demo_2min.md` — roteiro curto para a demo do Streamlit.
- `prints/` — capturas das telas principais, para o plano B do anexo.

## Onde cada critério do guia aparece

| Critério do guia | Onde ver |
|---|---|
| Resposta e pedido nos primeiros minutos | Visão geral |
| Regra dos 3 números | Visão geral |
| Problema com número que dói | Diagnóstico |
| Teste em período posterior | Modelo |
| Métrica em “de cada 10” | Visão geral e Modelo |
| Comparação com alternativa simples | Modelo e Negócio & piloto |
| Impacto em três cenários | Negócio & piloto |
| Recomendação com dono, prazo e custo | Negócio & piloto |
| Riscos e monitoramento | Negócio & piloto |
| Demo curta de 1–2 minutos | Simulador → roteiro de demonstração |
| Anexo técnico | Dados & método |

## O que ainda é entregável separado

O guia pede três itens: apresentação, pipeline do modelo com Docker e Streamlit. Este repositório entrega o **Streamlit** e o material de apoio. O pipeline oficial do modelo está em `projeto-bootcamp/` e precisa ser empacotado com Docker separadamente.
